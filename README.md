# Yorta Yorta Vegetation Monitor

## Overview

Yorta Yorta Vegetation Monitor is a proof-of-concept web application developed after my experience working with the Yorta Yorta community in Victoria, Australia.

The aim of the project is to explore how freely available satellite imagery can be used to visualise vegetation change across Yorta Yorta Country in a simple and accessible way.

The application generates an automated report including a vegetation change map, summary statistics and a printable PDF.

---

## Objectives

- Monitor vegetation change over time.
- Automatically generate a simple environmental report.
- Demonstrate how GIS and remote sensing can support environmental monitoring.
- Build a reproducible GIS workflow using open data.

---

## Current features (V1)

- Fixed study area (Yorta Yorta Country)
- Vegetation change analysis (2010–2025)
- Gain / Loss vegetation map
- Cultural places displayed on the map
- Buffer around cultural places
- Automatic PDF report
- Summary statistics

---

## Disclaimer

This application is a proof of concept developed for educational and portfolio purposes.

The application visualises vegetation change derived from publicly available satellite imagery. It does not assess cultural significance or determine the causes of environmental change.
